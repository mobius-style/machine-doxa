# Exploratory analysis plan — machine consensus

DoD: reproduce input counts and published H2/H3; run the complete prespecified reanalysis below with uncertainty and controls; produce a revised manuscript and supplement with receiver-side checks. No public posting or submission. Existing files are preserved.

Status: EXPLORATORY, unreviewed. This plan precedes this run, NOT data collection. Aggregate previous results and source scripts have been seen. No newly collected model or human data; no independent replication claim. Units are items conditional on these fixed models, not independent model replications. UTF-8, canonical option labels A-D, rotation mapping canonical=(display+rotation) mod 4. Inference conditional on curated items and complete-case selection.

Inputs: original battery, 21 included sessions, five published base-checkpoint probability records for all 180 items; hashes in input_manifest.json. Never source from analysis output. Missing or zero letter mass fails rather than becomes an empty distribution. Saved top-k letter probabilities are rounded/truncated: explicitly retain this measurement limitation.

A. Reconstruct registered subject modals (ties=NR), layer counts, H2 effect, H3 kappa. Reproduce original scripts on snapshot only. Establish full item exclusion ledger.
B. H2 (48 complete norm/preference items): estimate logistic consensus ~ norm + pooled determinacy (continuous). Report norm OR, profile likelihood 95% CI and LR p; also full model with quadratic determinacy as sensitivity, no selection. Report common-range support and optimal one-to-one nearest determinacy matching without replacement within absolute 0.05 caliper; maximize pair count then minimize total distance. Report matched risk difference, exact discordant-pair test, paired bootstrap 95% CI (10000 replicates). Repeat calipers 0.025 and 0.10 as disclosed sensitivity. No causal or normative construct identification claim from adjustment. Failure: no common support, unstable coefficient/CI or matched uncertainty including zero rules out declaring the ambiguity resolved.
C. Concentration versus directional agreement: each base model distribution is letter-normalized per rotation, mapped to canonical options, then averaged over four rotations. Let q_mi be this distribution. D_i is the old mean rotational peak, C_i=mean_m max(q_mi); A_i=mean over unordered model pairs of dot(q_mi,q_ni). Uniform A=0.25; A can be low when confident models disagree. Both measures use only base weights and never subject labels. Main scope: 81 valid habitus items. Logistic consensus ~ D + A versus D only; report A OR per 0.1, profile CI and nested LR p. Compare leave-one-item-out prediction (standardized ridge logistic, C=1, fixed no tuning): D versus D+A, Brier and log loss, all predictions released. Same with C replacing D as prespecified metric sensitivity. Repeat metrics excluding both Gemma bases (family overlap with subjects) and one base family at a time; do not treat these as independent replications. Secondary scope all 129 valid items with norm/preference indicators. No mechanistic or training-causal claims.
D. Negative control: independently permute canonical labels for each base distribution per item, preserving peaks and per-model entropy exactly; 1000 fixed-seed permutations. Compare observed consensus/non-consensus A difference to resulting null; also compare A increment in nested logistic LR to null. This tests shared direction, not semantic correctness, and is not independent model sampling. Synthetic checks: sharp same-option vs sharp different-option distributions have identical concentration and different A; pure display-position preference averages to uniform after rotations. Known-broken reverse-rotation mapping must fail a constructed case. Verify input corruption rejected.
E. Uncertainty: bootstrap items within outcome groups for mean differences in D,C,A (10000 fixed-seed resamples); logistic profile intervals when estimable, explicitly unbounded otherwise. Holm across two main LR tests B and C. Secondary and sensitivity p values labeled unadjusted exploratory. No observed-power calculation. Design sensitivity simulated before loading outcomes for n=81 and n=48 at baseline probabilities .37/.69, standardized normal independent predictors, standardized log OR .5/1/1.5, 500 simulations each; generic simulation, not retrospective power or exact design.

Claim promotion: only if A adds held-out predictive performance under both D and C, survives removal of Gemma and label-permutation control, may claim base directional alignment supplies information beyond concentration in this fixed battery. Otherwise report a diagnostic or negative finding. H2 cannot be called a normative effect even if adjusted association remains because no independent human construct measurement exists. All trials and failures retained; no optional extra specifications to chase significance.

Six gates: G1 exploratory only; G2 single-dataset exploratory evidence, not peer-reviewed; G3 effect+CI+test+correction+design-sensitivity; G4 objective deterministic feature extraction verified, no new human or LLM judge labels, original authored labels remain limitation; G5 no performance/generalization claim, original contamination limits retained; G6 online neighboring-work check and explicit refutation controls. Final gates reported in review report.
